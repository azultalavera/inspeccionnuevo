# ClicSalud+ - Módulo de Inspecciones y Denuncias Sanitarias (`inspeccionnuevo`)

## Comandos para Levantar el Proyecto

El proyecto está compuesto por un frontend en **React + Vite** y un backend en **Express.js**.

### 1. Iniciar el Backend (API REST)

Abre una terminal y ejecuta:

```bash
npm run server
```

- **URL del Backend:** `http://localhost:3001`
- **Health Check:** `http://localhost:3001/api/health`

### 2. Iniciar el Frontend (Vite Dev Server)

Abre otra terminal y ejecuta:

```bash
npm run dev
```

- **URL del Frontend:** `http://localhost:5173/`
