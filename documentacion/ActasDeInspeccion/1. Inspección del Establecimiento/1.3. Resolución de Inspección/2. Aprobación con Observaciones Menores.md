# 2. Aprobación con Observaciones Menores

### Historia de Usuario

**Como** Inspector,
**Quiero** aprobar la inspección registrando hallazgos que no impiden el funcionamiento pero requieren seguimiento,
**Para** permitir la habilitación del lugar sin ignorar las mejoras pendientes.

### Criterios de Aceptación

- **Condición de Activación:** Se utiliza cuando existen observaciones de tipo "Rectificación" o comentarios en "Datos Generales" que, a criterio del inspector, no son críticos para la seguridad del paciente.
- **Registro de Compromiso:** El sistema debe listar las observaciones menores para que queden asentadas en el Acta de Inspección como "Sugerencias de Mejora".
- **Estado del Trámite:** El trámite cambia a `ACEPTADO INSPECCIÓN.`
- **Historial:** Estas observaciones deben quedar visibles para la próxima auditoría o renovación del establecimiento.
