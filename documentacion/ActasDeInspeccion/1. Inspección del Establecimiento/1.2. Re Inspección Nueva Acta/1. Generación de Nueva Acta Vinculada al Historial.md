# 1. Generación de Nueva Acta Vinculada al Historial

### Historia de Usuario

**Como** Inspector,  
**Quiero** generar una nueva instancia de inspección (Acta N+1) cuando las respuestas de emplazamiento del efector no son suficientes,  
**Para** realizar una nueva verificación presencial vinculada a la inspección del trámite.

### Criterios de Aceptación

- Al ejecutar la acción **"Registrar Nueva Acta"**, el sistema debe crear un nuevo registro de inspección manteniendo el vínculo con el Acta anterior.

- El sistema debe heredar automáticamente la tipología y la configuración maestra utilizada en la inspección inicial (Snapshot original).

- El estado del trámite debe actualizarse a `ACEPTADO DOCUMENTACIÓN AUDITORÍA`.

- Debe generarse un nuevo número de Acta correlativo para mantener la trazabilidad.
