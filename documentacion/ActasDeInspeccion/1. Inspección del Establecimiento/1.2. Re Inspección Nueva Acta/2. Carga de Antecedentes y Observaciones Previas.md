# 2. Carga de Antecedentes y Observaciones Previas

### Historia de Usuario

**Como** Inspector,  
**Quiero** visualizar las inspecciones anteriores (deshabilitadas para su edición) junto con el apartado de respuesta de emplazamiento que envió el efector,  
**Para** enfocar la nueva auditoría en los puntos críticos pendientes teniendo todo el contexto a la vista.

### Criterios de Aceptación

- La pantalla de inspección debe mostrar las inspecciones anteriores en modo de solo lectura (deshabilitadas para su edición), asegurando que el registro histórico no pueda ser modificado.
- El sistema debe integrar un apartado visible con la "Respuesta de Emplazamiento" y los adjuntos que envió el efector para cada una de las observaciones previas (Emplazamientos).
- **Interfaz de Acta de Revisión:**
  - El **Resumen de Observaciones** debe ser visible en la parte superior.
  - La sección interactiva debe limitarse a la validación/rechazo de emplazamientos previos.
  - No se permite la carga de nuevas observaciones generales.
  - Botones de acción obligatorios: **"Emplazar"** y **"Registrar Nueva Acta"**.
