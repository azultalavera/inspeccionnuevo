# 1. Revisión Digital de Documentación Enviada

### Historia de Usuario

**Como** Inspector,  
**Quiero** revisar de forma digital las respuestas y evidencias cargadas por el efector ante los emplazamientos realizados,  
**Para** evaluar si los descargos justifican técnicamente la subsanación de las irregularidades.

### Criterios de Aceptación

Los hallazgos se presentan organizados en dos secciones: **Datos Generales** y **Datos del Trámite**, siguiendo la misma estructura con la que el efector cargó sus respuestas.

---

**Sección Datos Generales**

Cada apartado agrupa los ítems marcados como NO durante la inspección o cualquier otra observación cargada por el inspector.
Para cada ítem, el sistema muestra en una vista comparativa:

| Campo         | Descripción                                                                                                         |
| ------------- | ------------------------------------------------------------------------------------------------------------------- |
| Origen        | Sección relacionada a la observación.                                                                               |
| Categoría     | Subsección                                                                                                          |
| Observaciones | Obesrvacion cargada por el inspector                                                                                |
| Acción        | Botón para visualizar la respuesta de emplazamiento. Botones para marcar el ítem como **ACEPTADO** o **RECHAZADO**. |

---

**Sección Datos del Trámite**

La sección Datos del Trámite se organiza en **tres sub-secciones**, cada una agrupando un tipo distinto de irregularidad registrada durante la inspección:

---

**Sub-sección: Diferencias Constatadas**

Agrupa los ítems donde existe una discrepancia entre lo declarado por el efector y lo observado por el inspector (ej.: diferencia en cantidad de camas, equipos, personal).

| Campo         | Descripción                                                                                                                                                  |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Origen        | Servicio o área relacionada a la diferencia constatada.                                                                                                      |
| Categoría     | Subsección o elemento específico con diferencia.                                                                                                             |
| Observaciones | Detalle de la discrepancia (ej.: `DECLARADO: 34, OBSERVADO: 55`).                                                                                            |
| Acciones      | Botones para marcar el ítem como **ACEPTADO** o **RECHAZADO**. Si no hay ítems, se muestra el mensaje: _"No hay observaciones registradas en esta sección."_ |

---

**Sub-sección: Documentos Observados**

Agrupa los documentos que presentaron observaciones durante la inspección. Si no existen ítems registrados, se muestra el mensaje: _"No hay observaciones registradas en esta sección."_

| Campo         | Descripción                                                    |
| ------------- | -------------------------------------------------------------- |
| Origen        | Documento o área de procedencia de la observación.             |
| Categoría     | Tipo o nombre del documento observado.                         |
| Observaciones | Detalle de la observación registrada por el inspector.         |
| Acciones      | Botones para marcar el ítem como **ACEPTADO** o **RECHAZADO**. |

---

**Sub-sección: Inconsistencias Observadas**

Cada apartado agrupa los ítems marcados como NO durante la inspección o cualquier otra observación cargada por el inspector.

| Campo         | Descripción                                                                                   |
| ------------- | --------------------------------------------------------------------------------------------- |
| Origen        | Sección normativa o área relacionada a la inconsistencia.                                     |
| Categoría     | Elemento específico en el que se detectó la inconsistencia (ej.: _Elemento no especificado_). |
| Observaciones | Estado del incumplimiento (ej.: `NO CUMPLE`).                                                 |
| Acciones      | Botones para marcar el ítem como **ACEPTADO** o **RECHAZADO**.                                |

---

- **Visor de Documentos:** Los adjuntos de ambas secciones deben poder abrirse y visualizarse directamente desde la plataforma, sin necesidad de descargas externas.
- **Persistencia:** Si un ítem es marcado como RECHAZADO.
- **Habilitación de botones de acción:** La lógica de habilitación considera la totalidad de los ítems de **ambas secciones** (Datos Generales y Datos del Trámite, incluyendo las tres sub-secciones) en conjunto. Mientras exista al menos un ítem sin revisar, ambos botones permanecen deshabilitados.

**Botones**

| Condición                                            | Botón habilitado           |
| ---------------------------------------------------- | -------------------------- |
| Todos los ítems **ACEPTADOS**                        | **+ Nueva Acta**           |
| Al menos un ítem **RECHAZADO** (y el resto revisado) | **NO APROBAR**             |
| Uno o más ítems **sin revisar**                      | Ninguno (ambos bloqueados) |


- **Nueva Acta:** Al apretar el botón **+ Nueva Acta** (habilitado cuando todos los ítems son aceptados), el sistema debe redireccionar a una nueva pestaña (tab) correspondiente al acta $n+1$.
