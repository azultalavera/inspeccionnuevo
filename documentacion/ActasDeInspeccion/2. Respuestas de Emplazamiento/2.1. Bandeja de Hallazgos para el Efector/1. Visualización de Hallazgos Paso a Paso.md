# 1. Visualización de Hallazgos en la Pestaña Inspección

### Historia de Usuario

**Como** Efector,  
**Quiero** acceder a la pestaña "Inspección" y revisar en detalle el acta y cada irregularidad detectada por el inspector,  
**Para** comprender los motivos del dictamen, conocer las acciones correctivas requeridas y acceder a los documentos oficiales del acta.

### Criterios de Aceptación

---

**Título de la Pantalla**

- Si el acta está **aprobada**, el título principal de la pantalla debe mostrarse como **"Acta de Inspección"**.
- En cualquier otro estado, el título se muestra como **"Respuestas Emplazamiento"**.

---

**Botones de acceso a documentos (siempre visibles)**

Independientemente del estado del trámite, la pantalla debe mostrar siempre los siguientes botones, cada uno referido al acta en particular:

| Botón                           | Comportamiento                                                                                                                                      |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ver Reporte de Inspección (PDF) | Permite visualizar el reporte de esa inspección en particular en formato PDF.                                                                       |
| Ver Acta de Inspección          | Abre un modal "Visualización de Acta de Inspección" con todos los datos del acta inhabilitados para su edición, tal como el inspector los completó. |

---

**Alerta de estado del acta**

- Si el acta fue **aprobada**: se muestra una alerta destacada (ej. en color verde con el texto **"INSPECCIÓN APROBADA"**) con el mensaje: _"El proceso de inspección fue aprobado, su trámite puede continuar."_
- Si el acta fue **emplazada**: se muestra una alerta **"ACTA EMPLAZADA"** con el plazo de emplazamiento otorgado, especificando el tiempo concedido (por ejemplo, _"El inspector ha otorgado un plazo de 5 días para subsanar las observaciones y documentos rechazados."_) y la **Fecha límite** exacta calculada para el efector.

---

**Conclusión Final del Acta**

El sistema debe incluir un apartado **"CONCLUSIÓN FINAL DEL ACTA"**:

- **Observación General:** Si el inspector dejó alguna observación o conclusión general, el sistema debe mostrarla. Si no se cargó ninguna observación, el recuadro puede no mostrarse o indicar que no hay observaciones registradas.
- Evidencia fotográfica adjunta, si fue cargada.

---

**Sección Datos Generales**

> Solo se incluyen en esta sección los ítems cuya respuesta es **Sí/No** y que el inspector marcó como **NO**.

Cada apartado identifica una sección de datos generales observada y contiene una tabla con las siguientes columnas:

| Campo                 | Descripción                                                                      |
| --------------------- | -------------------------------------------------------------------------------- |
| Tipo de requisito     | Requisito inspeccionado que presenta la irregularidad.                           |
| Observación           | Comentario del inspector, si fue registrado.                                     |
| Evidencia fotográfica | Imagen adjuntada por el inspector, si fue cargada.                               |
| Acción                | Botón para cargar la respuesta de emplazamiento correspondiente a ese requisito. |

---

**Sección Datos del Trámite**

> Solo se incluyen en esta sección los ítems marcados como **Irregularidad** por el inspector.

Cada apartado identifica un paso del trámite observado y contiene una tabla con las siguientes columnas:

| Campo                 | Descripción                                                                       |
| --------------------- | --------------------------------------------------------------------------------- |
| Origen observado      | Nombre del ítem inspeccionado, con la cantidad declarada y la cantidad observada. |
| Observación           | Comentario del inspector, si fue registrado.                                      |
| Evidencia fotográfica | Imagen adjuntada por el inspector, si fue cargada.                                |
| Acción                | Botón para cargar la respuesta de emplazamiento correspondiente a ese requisito.  |

---

**Botones de acción**

| Botón   | Comportamiento                                                               |
| ------- | ---------------------------------------------------------------------------- |
| Volver  | Regresa a la pantalla principal sin guardar cambios.                         |
| Guardar | Persiste el progreso actual de forma parcial.                                |
| Enviar  | Habilitado únicamente cuando todas las observaciones han recibido respuesta. |

---

Al confirmar el envío, el trámite vuelve a aparecer en la bandeja del Inspector para su revisión.
